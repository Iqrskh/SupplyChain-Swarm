# 🚚 SupplyChain-Swarm

### LLM-Powered Agentic AI Supply Chain Decision Support System

SupplyChain-Swarm is a Python-based intelligent supply-chain simulation platform that combines **Machine Learning, Agentic AI, Large Language Models (LLMs), Generative AI, Retrieval-Augmented Generation (RAG), and Responsible AI**.

The system uses specialized agents for demand forecasting, inventory analysis, supplier risk evaluation, and procurement decision-making. A locally running **Llama 3.2 LLM through Ollama** provides natural-language explanations, while a RAG layer retrieves relevant supply-chain policies from a project-specific knowledge base.

The complete system is presented through an interactive **Streamlit dashboard**.

---

## 📌 Project Overview

Modern supply chains face challenges such as:

- Uncertain customer demand
- Inventory shortages
- Excess inventory
- Supplier delays
- Changing supplier costs
- Supplier reliability and risk
- Supply-chain disruptions

SupplyChain-Swarm addresses these challenges through a **multi-agent decision-support architecture**.

Each specialized agent performs a specific supply-chain task, while the Coordinator Agent integrates their results.

The system is further enhanced with:

- 🤖 Local LLM
- ✨ Generative AI
- 📚 RAG
- 🛡️ Responsible AI
- ⚙️ Intelligent automation

The LLM does not replace the existing supply-chain calculations. Instead, it explains the results generated by the specialized agents using retrieved project knowledge.

# 🎯 Objectives

The main objectives of SupplyChain-Swarm are:

- Forecast future product demand
- Analyze current inventory levels
- Calculate stockout risk
- Determine reorder requirements
- Evaluate supplier risk
- Compare supplier characteristics
- Recommend procurement quantities
- Select suitable suppliers
- Estimate procurement cost
- Simulate supply-chain disruption scenarios
- Provide natural-language AI explanations
- Retrieve relevant supply-chain policies using RAG
- Provide grounded and responsible AI-assisted decision support

# 🤖 Multi-Agent Architecture

The system contains the following specialized agents.

## 📈 Demand Agent

Forecasts future product demand using historical supply-chain data.

The forecasting component produces the predicted demand used by downstream agents.

---

## 📦 Inventory Agent

Analyzes:

- Current inventory
- Predicted demand
- Safety stock
- Lead-time demand
- Reorder point
- Stockout risk
- Recommended order quantity

---

## ⚠️ Supplier Risk Agent

Evaluates suppliers using factors such as:

- Unit cost
- Lead time
- Reliability
- Risk score
- Risk level

---

## 🛒 Procurement Agent

Uses inventory and supplier information to determine:

- Supplier selection
- Order quantity
- Estimated procurement cost
- Procurement decision reasoning

---

## 🧠 Coordinator Agent

Coordinates the specialized agents and combines their outputs into a unified supply-chain result.

The Coordinator Agent follows the workflow:

```text
Demand
   ↓
Inventory
   ↓
Supplier Risk
   ↓
Procurement
   ↓
Final Supply-Chain Result
